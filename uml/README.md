# Modelos UML de Easygest
En esta sección se organizan los modelos UML elaborados durante el análisis y diseño del sistema Easygest utilizando Visual Paradigm Online.

## Diagramas realizados

### Diagrama de casos de uso
Representa las principales funciones que los usuarios pueden realizar dentro de Easygest y la interacción de los actores con el sistema.

### Diagrama de clases
Representa la estructura principal del sistema mediante clases, atributos, métodos y las relaciones existentes entre ellas.

### Diagrama de secuencia
Representa el flujo de interacción entre los diferentes elementos del sistema durante el proceso de registro de un pedido, mostrando el orden en que se realizan las operaciones.

### Diagrama de actividad
Representa el flujo de las actividades realizadas dentro de un proceso de Easygest, incluyendo decisiones y caminos alternativos, como la comprobación de la disponibilidad de un producto.

## Herramienta utilizada

Los modelos UML fueron elaborados utilizando Visual Paradigm Online como herramienta de modelado y diseño.
