# Requisitos del sistema Easygest
En esta sección se documentan los principales requisitos identificados durante el análisis del sistema Easygest.

## Requisitos funcionales
- RF01: El sistema debe permitir registrar información de los productos.
- RF02: El sistema debe permitir consultar la disponibilidad de productos.
- RF03: El sistema debe permitir registrar pedidos.
- RF04: El sistema debe permitir gestionar las operaciones de recepción y almacén.
- RF05: El sistema debe permitir realizar el proceso de facturación.

## Requisitos no funcionales
- RNF01: El sistema debe presentar una interfaz clara y fácil de utilizar.
- RNF02: El sistema debe proteger la información almacenada.
- RNF03: El sistema debe responder de manera adecuada a las solicitudes del usuario.
- RNF04: El sistema debe mantener la información organizada y disponible.
- RNF05: El sistema debe facilitar su mantenimiento y futuras mejoras.
