# Gestión del avance del proyecto Easygest

## Organización del trabajo
El desarrollo de Easygest fue organizado mediante GitHub Projects, utilizando un tablero Kanban para facilitar el seguimiento de las diferentes actividades realizadas durante el proyecto.

El tablero se encuentra dividido en los siguientes estados:
- Backlog
- Por hacer
- En progreso
- En revisión
- Finalizado

Esta organización permite identificar de manera sencilla cuáles actividades están pendientes, cuáles se encuentran en desarrollo, cuáles necesitan revisión y cuáles ya han sido completadas.

## Tareas técnicas

Durante el desarrollo del proyecto se registraron tareas relacionadas con diferentes áreas del sistema, entre ellas:
- Análisis y definición de requisitos.
- Diseño de la interfaz.
- Elaboración de modelos UML.
- Definición de la arquitectura.
- Diseño y organización de la base de datos.
- Validación de requisitos.
- Documentación del proyecto.
- Realización de pruebas.
- Ajustes del sistema.
- Seguimiento del avance del proyecto.

Las tareas fueron clasificadas utilizando información como tipo, prioridad, responsable o rol, fecha estimada y estado.

## Gestión de prioridades
Las prioridades permiten identificar cuáles actividades requieren mayor atención. Para organizar el proyecto se utilizaron niveles de prioridad alta, media y baja según la importancia de cada tarea.

## Seguimiento
El tablero de GitHub Projects permite visualizar el avance general de Easygest y mover las tareas entre los diferentes estados según el progreso alcanzado.
De esta manera, el equipo puede conocer qué actividades necesitan atención y cuáles han sido completadas.
 
## Riesgos identificados
Durante la planificación y seguimiento del proyecto se consideraron riesgos que podrían afectar su desarrollo, como retrasos en las tareas, errores en los requisitos, dificultades técnicas y problemas durante la integración de los diferentes componentes.
Para estos riesgos se consideraron acciones de respuesta como revisar periódicamente el tablero, validar los requisitos, realizar pruebas y mantener actualizada la documentación.
